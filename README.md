## 7. 基准测试的毫秒原则

**原文标题**: Benchmark in Milliseconds

**原文链接**: [https://matklad.github.io/2026/10/05/benchmark-milliseconds.html](https://matklad.github.io/2026/10/05/benchmark-milliseconds.html)

作者主张微基准测试的目标时长应调整至约300毫秒，核心理由有三：其一，毫秒取值范围（1–999）为整数，精度足以辨识小幅优化，且便于快速视觉对比，无需切换单位或引入浮点数；其二，低于10毫秒的测试易受解释器启动等固定开销干扰，而数百毫秒对计算机而言已足够长，足以稀释此类一次性开销，无需额外补偿机制；其三，数百毫秒恰好落在人类可感知的时间范围内，开发者能凭直觉判断快慢，而非仅依赖数字比较，优化后命令从"卡顿"变为"瞬间响应"的体验也颇具成就感。然而一旦超过1秒，多次运行以观察方差的成本将显著拖慢迭代节奏。文章最终点明其核心假设：基准测试的根本目的并非获取精确的性能数值，而是为作者提供充分的直觉，以支撑正确的设计决策。

**原文标题**: Mathematics of Geothermal Energy

**原文链接**: [https://www.ebsco.com/research-starters/power-and-energy/mathematics-geothermal-energy/](https://www.ebsco.com/research-starters/power-and-energy/mathematics-geothermal-energy/)

摘要：地热能源于地球形成及放射性衰变产生的热能，温度随深度递增，称"地热梯度"，平均约2.5–3°C/100米，地下6000千米处可达约5000°C。板块边界如环太平洋火山带是优质开发区。数学家与工程师运用拉格朗日-欧拉流动模型、随机优化模型、几何模型及MODFLOW三维有限差分模型等工具，研究孔隙介质中的热流与流体运动，相关方法亦延伸至神经外科和工业注塑等领域。地热供暖方面，热泵系统可在冷暖季反向传递热量，冰岛自20世纪20年代起成为利用先驱，但大规模地下水开采可能引发地面沉降。地热发电方面，1904年意大利建成全球首座地热电厂，蒸汽温度需达95°C以上方可直接驱动涡轮，较低温度则依赖低沸点工质。地热发电具备燃料成本极低、排放少、可输出稳定基荷电力、资源近乎无限等优势，但初期投资高昂、优质站点有限及审批输电难题制约了发展。2005至2010年间全球地热发电量增长20%，开发国数量增加52%。在气候变化背景下，地热能正获得新的关注。
