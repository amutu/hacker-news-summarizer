**原文链接**: [https://www.nytimes.com/2026/11/15/science/birdbrain-crows-birds-research-decision.html](https://www.nytimes.com/2026/11/15/science/birdbrain-crows-birds-research-decision.html)

## 3. MacBook Pro OLED 的 PWM 调光问题

**原文标题**: The MacBook Pro's OLED PWM problem

**原文链接**: [https://macanorak.com/the-macbook-pros-oled-pwm-problem-when-a-better-display-becomes-worse-to-use/](https://macanorak.com/the-macbook-pros-oled-pwm-problem-when-a-better-display-becomes-worse-to-use/)

苹果新一代 MacBook Pro 搭载"PROLED XDR"串联 OLED 显示屏，画质出众，但多位用户反映出现头痛、眩晕、恶心等不适症状，社区讨论集中指向 PWM（脉冲宽度调制）调光问题。Notebookcheck 实测显示，该 OLED 面板 PWM 频率仅 240Hz，而前代 Mini-LED 版本高达 14,880Hz，差距约 62 倍。OLED 并非没有 PWM，但不同面板实现方式差异巨大；该机型虽支持 DC 调光，仍保留 240Hz 闪烁。值得注意的是，许多用户此前长期使用 OLED 设备毫无不适，说明 PWM 敏感度是连续谱系而非二元对立。苹果曾在 iPhone 上提供"显示脉冲平滑"无障碍选项，但 Mac 端尚未提供类似功能。文章强调，即使问题仅影响少数人，苹果作为以无障碍见长的公司也理应重视，应像 VoiceOver 等特性一样为显示舒适度提供用户可控选项。作者建议潜在买家购买前到 Apple Store 实际体验，不要因 iPhone OLED 无不适就假定 MacBook Pro 也安全；现有 Mini-LED 版本仍是舒适替代，但随着苹果全面转向 OLED，若调光策略不改善，此问题或将持续困扰后续机型。

**原文链接**: [https://github.com/eclipse-mosquitto/mosquitto](https://github.com/eclipse-mosquitto/mosquitto)

Eclipse Mosquitto 是隶属于 Eclipse 基金会的开源 MQTT 协议代理服务器，支持 MQTT 5.0、3.1.1 及 3.1 版本。除核心代理外，项目还提供 C/C++ 客户端库及 mosquitto_pub、mosquitto_sub（发布与订阅）、mosquitto_ctrl、mosquitto_signal、mosquitto_passwd 等命令行工具。安装方面，各平台二进制包可从官网获取；Windows 与 Mac 使用 CMake 构建，其余平台使用 make。cJSON 为必需依赖，OpenSSL、SQLite3、pthreads、c-ares、libmicrohttpd 等为可选项，也可通过 vcpkg 一键安装。快速启动时，直接运行 mosquitto 命令即可开启代理（仅限本地匿名访问，适合测试），再用 mosquitto_sub 和 mosquitto_pub 完成订阅与发布。生产环境须配置监听地址与认证方式，不建议匿名公开运行。文档涵盖 man 页面、客户端 API 参考及协议介绍，源码托管于 GitHub。该项目由 Roger Light 创建，社区贡献者众多。
