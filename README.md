## 9. 有人于2026年9月报告了Java4Shell漏洞

**原文标题**: Someone reported java4shell bug in September 2026

**原文链接**: [https://github.com/openjdk/jdk/pull/32781](https://github.com/openjdk/jdk/pull/32781)

2026年9月9日，开发者albertnetymk向OpenJDK提交PR #32781，修复issue 8392044所描述的AVX-512 Base64解码器内存越界写入缺陷。该缺陷位于StubGenerator::generate_base4_decodeBlock()的x86_64 AVX-512 VBMI路径中：L_finalBit处理1至63个剩余字节时，若输入长度不足4（如64个"A"加一个"="），output_size初始为0，填充路径会使其递减为负值，生成错误掩码，导致stub在逻辑输出长度之外写入数据，破坏JVM堆内存。修复方案为在length小于4时提前返回Java层。该PR被标记为hotspot-compiler标签，需两位审查者（至少一名Reviewer、一名Author）审核。期间关联了多起JVM崩溃报告（GC线程、ArrayCopy等）。因超过8周无活动，PR于11月4日被系统自动关闭。11月19日，开发者hmilkovi在讨论中询问关闭原因，但未见后续回应。该事件还出现在Adoptium月度发布状态追踪及HackerNews日报中，引发社区关注。
